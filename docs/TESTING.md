## 复现方法

```bash
flutter pub get
flutter analyze
flutter test
# 需要已经启动的 Android 模拟器
./tool/capture_android.sh emulator-5554
# 也可仅更新某张截图
./tool/capture_android.sh emulator-5554 14-select-barber
# 构建适用于 ARM64 Android 设备的演示安装包
flutter build apk --release --target-platform android-arm64
```

截图脚本先运行集成测试，将图片保存在 App 的临时目录，再使用 `adb run-as` 导出到 `docs/screenshots/`。这样可避免一次性将 25 张高分辨率截图编码进测试驱动的 JSON 响应。脚本默认从 `ANDROID_HOME`、`ANDROID_SDK_ROOT` 或 macOS Android SDK 默认目录查找 adb。

集成测试会清空此 App 的偏好数据，并在结束时再次清空，确保每次都从相同的演示状态开始；它不操作其他 App 的数据。结束后重新启动即可看到欢迎页。

## 截图约定

运行截图见 [截图索引](SCREENSHOTS.md)，Pixso 原图另存于 `reference/`。截图命名 `01-welcome.png` 至 `25-congratulations.png` 与设计稿顺序一致。输入框未强制弹出系统键盘，以便截图完整展示表单；实际点击可正常输入。

截图日期由设备当前日期生成，时段使用正确的 AM/PM。默认预约选中两天后的日期，示例预约在三天后。日历、图标和状态栏会随平台变化，不复刻设计稿的 iOS 系统 UI。

## 交付边界

该版本是完整页面与本地业务流程演示，没有接入真实门店和账户服务。以下内容需要后续业务接入：

| 功能 | 当前行为 | 接入需求 |
| --- | --- | --- |
| 登录/注册 | 邮箱、密码长度、重复密码校验，保存本地登录标记 | 身份验证 API 和安全凭证存储 |
| 忘记/修改密码 | 演示说明或表单校验，明确显示需后端支持 | 邮件/短信、当前密码验证、重置接口 |
| 地图/定位 | 原稿底图、可交互标记、缩放、复位 | 地图 SDK、密钥、权限、地理坐标和路线 |
| 预约 | 本地创建、保存、去重、取消 | 服务端可用时段、容量和并发控制 |
| 历史记录 | 一条用于呈现样式的历史示例 | 真实预约历史 API |
| 积分/优惠码 | 475 初始积分，演示码 `218876` 兑换一次 50 积分 | 服务端积分账本和优惠码校验 |
| 评论 | 当前会话中选择星级、填写内容和立即显示 | 评论 API、登录验证和持久化 |
| 头像 | 使用设计稿默认头像，点击进入资料编辑 | 图片选择、上传和存储 |
| 支付 | 显示选中服务价格 | 支付渠道和订单接口 |

资源来自用户提供的 Pixso 参考文件；字体使用随项目附带的 OFL 许可。安装包采用工程默认演示签名。正式发布需配置发布者自己的签名和业务服务。
